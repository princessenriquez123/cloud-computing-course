# Amazon Web Services (AWS) Research

## Brief Overview
Amazon Web Services (AWS) is a cloud computing platform provided by Amazon. It offers services such as computing, storage, networking, databases, security, and artificial intelligence. AWS was launched in 2006 and is used by businesses of different sizes around the world.

## Global Infrastructure
AWS operates a large global cloud infrastructure made up of Regions and Availability Zones. Currently, AWS has 39 geographic Regions and 123 Availability Zones around the world. This allows companies to deploy applications closer to their users and improve reliability.

## Cloud Management Console
The AWS Management Console is a web-based interface used to access and manage AWS cloud resources. Through the console, users can create virtual machines, manage storage, configure networks, monitor services, and manage security settings.

## Four Core Services
1. **Amazon EC2** – Provides scalable virtual machines and computing resources.
2. **Amazon S3** – Provides object storage for files, backups, applications, and other data.
3. **Amazon VPC** – Allows users to create and manage private virtual networks in AWS.
4. **AWS IAM** – Controls user identities, permissions, and access to AWS resources.

## Three Advantages
1. AWS offers a very wide range of cloud services.
2. It has a large global infrastructure that supports applications around the world.
3. AWS can easily scale resources depending on the needs of a business.

## Typical Enterprise Use Cases
AWS can be used for website and application hosting, data storage and backup, databases, disaster recovery, artificial intelligence, data analytics, and global e-commerce applications.
