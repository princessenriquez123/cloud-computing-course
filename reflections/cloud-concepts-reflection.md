# Cloud Concepts Reflection

Cloud computing has become a part of my everyday life, even before I fully understood what it was. Almost every day, 
I use applications like Google Drive, Facebook Messenger, and Canva for school, communication, and personal 
tasks. These services make my work easier because I can access them anytime and anywhere as long as I have an
internet connection.

Google Drive is a Software as a Service (SaaS) because I can store, edit, and share my files online without 
installing special software or managing any servers. It uses a **Public Cloud** since anyone with a Google account 
can use its services. Facebook Messenger is also a SaaS application because it allows me to send messages, make 
voice calls, and video call my family, friends, and classmates through the internet. It is also hosted on a Public Cloud 
because it is available to millions of users worldwide. Canva is another SaaS application that I often use to create 
presentations, posters, and social media designs. Like the other services, it is deployed on a Public Cloud, 
making it easy to access from different devices.

Learning about Git and GitHub helped me realize how important version control is, especially when working on projects 
with other people. Instead of worrying about losing files or accidentally deleting important work, Git keeps track of 
every change that is made. GitHub also makes collaboration much easier because everyone can work on the same project, 
review updates, and combine changes without creating confusion. I believe these tools are essential not only for cloud 
computing but also for software development in general. As I continue studying Cloud Computing, I know that understanding 
cloud services and using GitHub effectively will help me become more organized and prepare me for working on real-world IT 
projects in the future.
